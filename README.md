# EV Swap Network Operations Intelligence

## Business Problem

An electric motorcycle battery-swap operator needs visibility into
station demand, battery availability, customer waiting times and station
downtime.

The objective of this project is to build an interactive Power BI
dashboard that allows operations managers to identify network
bottlenecks and make data-driven operational decisions.

## Project Objectives

1. Monitor battery-swap demand across stations.
2. Identify peak demand periods.
3. Measure customer waiting times.
4. Monitor station downtime.
5. Identify stations experiencing battery shortages.
6. Compare station performance across the network.
7. Provide actionable operational recommendations.

## Tools

- Power BI
- Power Query
- DAX
- Python
- Git/GitHub

## Data

The project uses synthetic EV battery-swap operational data created
specifically for portfolio purposes.
